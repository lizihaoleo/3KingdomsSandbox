---
description: 把当前分支的推演记录整理成小说大纲，存到 outline/ 并提交
argument-hint: [对大纲的额外要求，可选]
---
额外要求：$ARGUMENTS

1. 定下线名 B：取 `sim/config.json` 的 `title` 里“·”后面的部分（如“穿越线”）；没有就用当前分支名（`git branch --show-current`，“/”换成“-”）。文件按线名命名，几条线的大纲才能放在同一个 outline/ 里互不覆盖。
2. 运行 `python3 tools/sim.py export --out outline/推演记录-B.md`。
3. 读完这份记录。如果太长读不完，先启动 general-purpose 子代理分段概括（每段几季，保留每个人物的关键抉择、动机与密信往来），再根据概括写大纲。
4. 以推演事实为骨架，写 `outline/大纲-B.md`。可以戏剧化取舍、合并次要事件、补足动机，但主要情节走向和人物抉择要忠于推演，并在每章注明对应第几季。结构：
   - 书名（3 个候选）与一句话卖点
   - 核心冲突与主题（主角身份秘密的张力、先知与改变历史的两难等）
   - 主要人物与人物弧光（6–10 人：起点、转折、终点，注明推演中的关键时刻）
   - 分卷大纲（时间跨度、核心事件、高潮）
   - 章节大纲（章名、时间、视角人物、情节要点 2–4 条、埋下或回收的伏笔、对应第几季）
   - 最值得重点写的 3–5 个场面
   - 后续推演可以发展的悬念
5. 如果 outline/ 下已有其他线的大纲，最后加一节“与其他线的分歧”，简述两条历史从哪里开始走向不同，并附上那条线大纲页面的链接。
6. 运行 `python3 tools/outline_page.py outline/大纲-B.md` 生成手机友好的 HTML。
7. `git add outline && git commit -m "大纲：B（至第N季）"`，然后用几句话告诉我大纲的主线。
