# 写作约定

## 结构

- 一章对应大纲的一章，四五千到六千字。章内用 `※` 分场景。
- 每章至少一个爽点；最后一场必须留钩子，下一章的事要在这一章最后露出来。
- 视角以刘禅为主，紧贴他的想法写。离开成都的戏（江陵、樊城、吴营）可以切到当事人，但每场只跟一个人。
- 推演里的走向和人物抉择不改；大纲第九节修订过的地方照大纲写。

## 主角

- 二十一世纪的普通人，读过《三国演义》和《三国志》，只记得大事，记不住日子，会把演义和正史记混。
- 现代的东西只能用在想法里，嘴上说出来必须是这个时代的话（“直径”这类词要在他心里换算掉）。
- 他最大的危险是说中太多。每次说中，都要有人记下来；每次圆谎，都要圆得不太圆。
- 他是十二岁的身体，会累，会怕，跪下磕头会磕出红印。

## 文风

- 短句，短段，多对话。一件事写清楚就往下走，不总结，不抒情，不在段尾点题。
- 用动作和东西写情绪：手抖、掉笔、橘子停在手里。不直接写“他很震惊”“心中五味杂陈”。
- 不用：仿佛、一丝、嘴角勾起、深吸一口气、眼中闪过、空气凝固、心中涌起、不禁、这一刻。
- 少用“不是……而是……”和三连排比。
- 古人说话用浅白的文言腔，不要整段文言；刘禅心里用现代口语。
- **密信可以用文言**：推演记录里各人的“密信致某某”可以直接引用原文，或稍作润色，用引用块（`>`）单独成段。一章引一两封，放在最要紧的地方：读信的人是谁、读完做了什么，紧接着写出来。刘禅自己写的信偏白话、带孩子气；诸葛亮、法正、陆逊、司马懿这些人的信用文言，越简越好。
- 史料原句（《出师表》《三国志》里的话）也可以用，同样单独成段，不要解释。

## 新人物登场

读者不一定熟读三国。每个有名有姓的人物第一次出场，都要让读者知道他是谁：

- **一般人物**：用旁人的对话或一两句带出身份，别写成百科。比如“他是糜别驾的亲弟弟，大王的小舅子”“这人是马良，眉毛里有几根白毛，荆州人都说‘马氏五常，白眉最良’”。
- **重要人物**（会反复出场、影响大局的）：除了点明身份，再借刘禅的视角讲一下这个人在“书上”（真实历史里）的结局，让读者看到这一世已经或可能走偏到哪里。三五句话，口语，带一点他的情绪，比如怕、可惜、庆幸。例：第1章讲陆逊“三年以后会在夷陵一把火烧掉刘备七百里连营”。
- 刘禅不在场的场景，可以在他后来听说这个人的时候补上历史结局。
- 同一个人只交代一次。写之前查 README 的“人物出场”表，表里已有的不再交代。

## 称呼

- 称呼跟着说话人、想事的人走。写谁的视角，就用谁的叫法：关银屏、关平管刘备叫“大王”“陛下”或“伯父”，管关羽叫“父亲”；只有刘禅叫刘备“父王”“父皇”，刘封叫“父王”“父皇”。叙述里称刘备用“刘备”“汉中王”“皇帝”。
见 [README](README.md) 的“人物出场”。新人物第一次出场时补进去。
