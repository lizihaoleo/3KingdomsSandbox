## 写作流程（第十一章起）

1. 动笔前读：大纲本章、`账本.md`、本 README 的文风约定与技巧表、推演记录对应回的摘要。不读前文全文，需要时按关键词查。
2. 以五章为一批写完，每章写完把“本章新增事实”追加进账本第七节，并更新账本各表。
3. 跑 `python3 tools/novel_lint.py novel/孤岛 --fill`，再跑一遍不带 `--fill` 的，清零。
4. 派一个复查代理，只读“这五章＋账本＋本 README”，找漏洞、看不懂和机械腔，按它的意见改。
5. 生成阅读页、发布、提交推送。大纲层面的改动才回头扫前文，用关键词定位，不重读全书。

## 文风约定

- 第三人称限知，每章以大纲标明的人物为主视角；需要换人时用分隔线另起一节，一节只跟一个人。
- 叙述克制，少用形容词和心理剖白，多用动作、物件和对话把心事带出来。人物的情绪尽量落在一件具体的东西上（一支烟、一张纸、一块手帕）。
- 对话短，留白多。人物说话各有分寸：沈墨言话少嘴毒；顾承舟客气、周全、从不把话说满；李士群和气，笑着说最重的话；陈恭澍只问事不问人；林知微的话像她讲的课文。
- 时代用语：弄堂、亭子间、老虎灶、黄包车、巡捕、越捕（安南巡捕）、包打听、烟纸店、死信箱。地名用当时的路名（霞飞路、福煦路、极司菲尔路、辣斐德路、福开森路、吕班路、静安寺路、北四川路、爱多亚路）。
- 史实节点按大纲第十二节史实索引写，不提前、不推迟。
- **电文、死信箱字条一律不写真名**，用代号：沈墨言＝鲁班（进组时自己挑的），林知微＝素琴，邵子钧在区里的电文中沿用 76 号账上的“老锁”。叙述里可以写真名，电文原文里不行。
- 枪战、搏斗可以正面写，写清动作、距离、地形和人的反应，写出紧张；刑讯仍以写前后和受刑者的身体反应为主，不写成猎奇。（作者二〇二六年十月改定）
- **新人物出场必须交代**：每章第一次露面的人物（包括前几章出现过、本章才第一次正面出场的），在他出场的那一段里用一两句说清三件事——是谁的人、什么职务来历、和在场的人是什么关系。能放进对话就放进对话（由别人说他，或他自己说漏嘴），放不进就用叙述一句带过，不另起段落做人物小传。真实历史人物（李士群、丁默邨、戴笠、影佐、晴气、吴四宝、郑苹如、周佛海……）第一次出场必须交代职务与来历；机关名（军统、76 号、梅机关、宪兵队特高课、中统）第一次出现必须说清是哪一边的、管什么。

## 写作中确定下来的细节（后文要沿用）

- 墨言被捕时住善钟路亭子间，三楼朝北，是林知微经同事的远房亲戚租下的；旧址在霞飞路。
- 第一章用对话交代的身份：墨言闸北人（家在宝山路，八一三那年烧掉，烧的那天他在苏州河这边）、圣约翰土木系四年级没念完、那年冬天进军统上海区行动组、王天木名单第十七名；承舟三个月前进 76 号（特工总部，丁主任挂牌、李副主任管事）；森田是宪兵中佐、特高课长；顾鸿年五月不肯把货盘给日商洋行，六月初以“布到了闸北游击队手里”的资敌罪名被扣，承舟同一个礼拜进的 76 号；陈恭澍八月底到任。
- 第一章墨言对三个知情人的推理不是排除，是权衡：关在牢里他不知道别处有没有人被捕，所以什么也证明不了。知微若是对面的人，他的命轮不到今夜；陈恭澍手里只是名册上一行字，若连他也是，上海区就死了；邵子钧是三人里唯一上过那三楼、看过晒台、在弄堂口看过死弄的人（搬家那天他以组长身份破例来帮忙，什么也没问、什么也没记——老特务不留破绽），又是王天木带出来的。他认定的是概率，第二章“老锁匠”是一次下注，第四章陈恭澍的三样东西才是证据。
- 四舍＝思孟堂四楼那间四人宿舍；两人常坐二十四路电车走极司菲尔路。
- 承舟与森田的死信箱：北四川路内山书店二楼第三格那本最旧的《辞源》夹层。
- “吸收”的现实逻辑（第一章墨言自己点破）：人进 76 号当夜区里就把他当死人，码本、联络点、住处全换；关一夜放回去还能算一条线，关十天半月回去就做不成线。所以李士群要的从来不是一条干净的内线，是悔过书和照片这个把柄，加上看军统怎么处置他——杀了，军统自损一个枪手；信了，就是一条线。“一个月”是李士群给承舟的外限，不是吸收的常规。
- 墨言被“吸收”后住吕班路亭子间，弄堂口烟纸店里每天换一个盯梢的人。
- 李士群第一次见墨言就注意到“言”字末笔收得轻（第三章），这是第三十二章笔迹之问的根。
- 墨言没有外号。大光明之后，李士群定下 76 号卷宗里只写他的代号“太平门”（第四章）。这个代号只从敌人嘴里说出来，叙述里不用。
- 林知微与沈家的关系：她在白利南路的女校教过小禾两年国文，是送小禾去考圣约翰的老师，墨言由此认识她。家书写给小禾、托“林先生”照应，在 76 号眼里是人之常情；信经小禾到知微手里，不碰区里任何一条线。
- 墨言明知不能排除知微，仍敢把“老锁匠”写给她，理由在第一章算过三层（信有地方去；两头不亏；去年冬天在霞飞路，师父的事、怎么入的行他只对她一个人说过，“宁可在她身上算错，也不肯不写”——这也是“一句只有她读得懂的话”成立的前提）：若知微是对面的人，信里没有一样东西是 76 号不知道的（邵子钧是组长，在王天木交出的名单上；知微若是他们的人，他们自然知道她），至多让他们知道“沈墨言猜到了”，他关在牢里猜到猜不到一样；若不是她，这是他唯一一次把话递出去的机会，把最疑的那个人递出去。两头不亏。
- 邵子钧在行动组里背后被叫作“老锁匠”：早年在闸北开过一爿锁铺做掩护，开锁的本事是那时练的。墨言去年冬天在霞飞路对林知微说过这个诨名，所以家书里“多年的老锁匠也会出错”她一读就懂；王天木给他的接头代号“老锁”也是从这个诨名来的，承舟在张阿六口供里看见“老锁”才和家书对上。
- 邵子钧的招供是半个真话（F02 在第一卷的两颗钉子）：第四章陈恭澍问“去年冬天要的是哪个门牌、九月初三王天木已在 76 号叫你交的是谁”，邵答“还是他的线”，陈恭澍记下不捅破；第五章陈恭澍电重庆“此节存疑拟续查”，重庆回“老锁案毋庸深究，留用照旧”，他烧了没再查。后面的钉子在大纲里：第十章师徒最后一面（“替我去经理处查一笔账”“只求死得有用”）、第十一章重庆回电“准其递话，事毕即处置”（陈恭澍经程伯雄雇的生手执行，墨言只收到“邵线已断”）、第十五章林知微查出“奉渝电第××号”签条、陈恭澍说“放下”。真相（上头自己人拿门牌换温致远）到第 25、30 章才揭。
- 邵子钧软禁在福开森路一楼的空屋，程伯雄的生手看门；他“老锁”“裁缝”一人两名，按月领了十二回钱。
- 八仙桥后巷牺牲的军统枪手叫小凌，二十三岁，宁波人；陈恭澍另有一本记名字的簿子。

- 沪渝断电的规矩：上海丢一个报务员，重庆即视所有码本已失，全部静默，新本经香港送到快则半个月、慢则一个月（第六章新码本缝在绸缎里运到、十日子夜叫通重庆）。

- 墨言在王天木被捕当夜奉命搬离霞飞路，在朋友家打了二十几天地铺，九月二日住进善钟路。外滩备用台是王天木在任时设的，只每月试机，区里八月以为它干净没动；李士群八月就拿到地址，留到十一月等墨言那一问。

## 谍战技巧表

用法：每个技巧只用一次，必须推动情节（救人、露馅、钓人），用过就把“状态”改成“已用”。按谋略谱分人：墨言管空间路线，承舟管文书笔迹，林知微管电码文字，森田管刑侦痕迹，李士群管人心，陈恭澍管组织纪律。敌人也要用，敌人用比主角用更紧张。

史实边界（1939–41 年上海）：没有便携录音机，钢丝录音机要到战后才普及。能录音的只有两样：一是办公室用的蜡筒口述机（Dictaphone 一类，一筒只录几分钟，声音很糙）；二是唱片公司的刻片机（百代在上海有厂），笨重，只能固定在一间屋里。窃听器是连着长线的话筒，耳机在隔壁屋。所以“窃听”主要靠电话接线生、板壁、茶房娘姨；“伪造录音”在这个年代写成冒名电话更可信，电话线路杂音大，会口技的人学一个人说话，对方很难分辨。
