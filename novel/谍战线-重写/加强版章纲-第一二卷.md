# 加强版章纲 · 第一、二卷（第1—15章）

## 总原则

- **不动的**：史实（郑苹如、高宗武、密约、汪伪还都等的日子和结果）；人物命运；全书大走向和结局；两人"认出而不说"的核心。
- **要改的**：每章都按"危机—出手—反转—钩子"四拍写。
  1. **危机**：开场三页内压上来，并且有期限，读者知道"到什么时候不解决就完了"。
  2. **出手**：主角当着读者的面出手。先不交代计划，读者跟着悬着，揭开时才明白。
  3. **反转**：计划里出一个意外，主角当场应变。读者没想到，回头一想又在情理之中。
  4. **钩子**：章末留一个新麻烦，最好是更大的。
- **幕后搬到台前**：原来靠转述、靠事后交代的高光（测向车、八仙桥、大光明的混战、高宗武出走），改成主角在场亲历。
- **两人正面交锋**：第一、二卷里墨言和承舟当面或隔一扇门的对手戏，由现在的三场加到七场。
- **敌人逼到眼前**：森田、李士群、吴四宝、晴气的压力，从"一句话、一张纸"改成人站在三步之外。
- **砍掉的**：章与章之间大段的回想和心里算账。算账改成对话或动作；一章至多留一段内心独白。

标 **★** 的是情节改动，没标的是原有情节，只改写法。每章最后列出对后面章节的连带影响。

## 第一卷 · 雨夜

### 第1章 四舍（1939.9.12 雨夜）

- **危机**：开场不再从窗纸破角往下看，直接写抓捕。
  - ★墨言听见弄堂口刹车声，从晒台翻上邻家屋顶，发现死弄那头也站了人。
  - ★屋脊上搏斗：一个打手被他用撬锁的铁丝扎穿手背，另一个被他从晒台推下去，第三个用枪托砸中他的后脑。
  - 读者第一页就知道他是枪手，不是书生。
- **期限**：★李士群的规矩是四十八钟头。四十八钟头里情报科问不出东西，人就交给吴四宝的刑房。吴四宝第一场亲自露面，拍拍墨言的脸："两天以后见。"
- **出手（反审）**：保留。承舟递老刀牌，墨言反过来审他："名单上只有我十天前退掉的旧址。"
  - 改法：写成两人一来一回的交锋，各有三次进攻、三次退守，不让墨言一个人占尽上风。
  - 承舟也要有一记重的："你妹妹在圣约翰念一年级，住女生宿舍二楼。"墨言第一次变了脸色。
- **算账**：三个人里推出邵子钧，原来那一大段心里算账压到半页。"宁可赌一次她不是出卖者，也不能不写"这句保留。
- **钩子**：★承舟深夜到虹口，森田把一张空白口供推到他面前："四十八钟头，他开口以前，先开给我看。"隔着铁栏，父亲在咳血。
  - 章末一句：承舟回到七十六号，看了看表，还剩三十一个钟头。
- **影响**：后文的旧伤要统一（墨言后脑、打手手背）；吴四宝提前和墨言结仇，第3章、第五卷可以回收。

### 第2章 老锁匠（9月中下旬，林知微视角）

- **危机**：家书到了知微手里，她读出"老锁匠"指邵子钧。
  - ★第二天邵子钧亲自来女校找她，说"墨言有信来没有？区里想知道他在里面说了什么"。内鬼就坐在对面喝她泡的茶，问的正是这封信。
- **出手**：★知微当面撒谎。她把信给邵看，邵看不出那句话；她又若无其事地问起搬家那天晒台上的事，邵答出了一个只有在场的人才知道的细节（死弄口那棵泡桐），等于自己认了。
  - 读者看着一个女教员面不改色地套出组长的话。这是知微的第一个高光。
- **反转**：★邵走后，她发现自己被跟了：跟她的是程伯雄的人。她不知道程伯雄替谁跑腿，只能把要写给区长的信拆成两封，分两处投。
- **承舟线**：张阿六供出"老锁"。承舟手里有墨言家书的抄件，读懂了"老锁匠"。
  - ★改成一场戏：他可以把这句话划掉再放信出去，他拿起笔又放下，信照原样寄走。读者看着他做了这个选择。
- **钩子**：森田停了父亲的药，药房的日本军医当着承舟的面把药瓶收回柜子。

### 第3章 半个名字（9.14—10.4）

- **危机**：★四十八钟头到了。墨言被拖进吴四宝的刑房，绑上老虎凳。
  - 写刑讯的威胁和恐惧，不写细节。
  - 吴四宝问的不是口供，是"你那个同学给了你什么好处"，矛头对着承舟。
- **出手**：★承舟带着李士群的条子进来要人。吴四宝不放，两人当着墨言的面对峙，吴四宝的手已经按在枪上。
  - 承舟赢在一句话："主任要的是活口，你打死了他，名单上那个人谁去找？"
  - 第一次让读者看见承舟在七十六号是怎么活下来的。
- **交易**：地下室里"半个名字"保留。"这个名字在你口袋里，值伯父一条命；摆到森田桌上，一文不值。"
- **悔过书、照相**：保留。"字写得丑，主任别见笑。"
- **反转**：放人的钟点被承舟卖给了森田，墨言一出门就认出两拨尾巴。
- **高光 · 大光明**：★整场写在台前，是全卷第一个大场面。
  1. 墨言进场，两拨尾巴一前一后坐下，其中一个就坐在他身边。
  2. 银幕上的美国片放到一半，身边那人的手搭上他的手腕："沈先生，看完再走。"
  3. 换片的十几秒全场漆黑。墨言把那人的手按在另一拨尾巴的椅背上，自己蹲下，沿过道摸到太平门。
  4. 读者在黑暗里只听见声音：椅子翻倒、有人骂日本话、有人喊"抓住了"。
  5. 散场灯亮，宪兵便衣和吴四宝的人互相揪着领子。
- **钩子**：李士群听完两拨人的报告，在笔录上写下"太平门"三个字："往后卷宗里不写他的名字。"同一页上，他用红笔圈了"顾承舟"。

### 第4章 测向车（10月上中旬）

- **危机**：区长陈恭澍在空屋审邵子钧，邵认下门牌。
  - ★墨言要求在场。他隔着一道板壁听师父认罪，这是师徒最近的一次。区长不许他出声。
- **出手（定计）**：让邵报假电台位置，引测向车进辣斐德路，法捕房埋伏。保留，但写成台前的行动。
- **反转**：★十月十三日子夜，测向车提前一个钟头到，法捕房的人还没到位。
  - 跟着车来的还有吴四宝的一车打手，要先进屋抓报务员。
  - 屋里只有墨言一个人和一台空机器。
- **高光**：★墨言一个人拖住他们一个钟头：
  - 开机发报，让测向车以为人还在；
  - 拉断楼梯口的电灯；
  - 从后窗把一盆煤球泼到弄堂里引来巡捕；
  - 打手冲进来的时候他已经在隔壁屋顶上。
  - 法捕房的车到了，测向车连人带机被扣。整场在台前，有枪声，有近身肉搏。
- **钩子**：李士群在办公室翻家书抄件，发现"修钟的师傅"就是测向车，笑了："好线才值得钓。"
  - 同一夜，森田认定承舟走漏了消息，父亲又被停药。墨言赢的这一局，账记在承舟头上。
  - 章末：承舟站在父亲的牢门外，什么也没说。
- **影响**：账本上测向车的细节（墨言不在场）改为在场；陈恭澍对墨言的信任由此建立，第5章可以少写一段铺垫。

### 第5章 裁缝（10月中—11月）

- **危机**：★期限是一张火车票：吴四宝的接头人二十四日去南京，过了这天线就断了。区长要在二十三日动手。
- **高光**：★八仙桥后巷伏击改成枪战，墨言亲自带队，视角从陈恭澍改为墨言（陈恭澍的电报部分保留为短节）。
  1. 接头人身边多了两个保镖，情报里没有。
  2. 小凌中枪，死在墨言怀里，说的是宁波话。
  3. 墨言追出两条街，在电车轨道上把接头人打倒，从他身上搜出火车票和账页"裁缝，月五十，照旧"。
- **小梅线**：★洗衣车过北楼岗哨时，宪兵用刺刀挑开被单，药就压在最底下。刺刀停在离药包一寸的地方，阿香嫂和宪兵说起了天冷。老人撑过了停药。
- **钩子**：账页上"裁缝"两个字。墨言看着这两个字，知道师父领了一年钱，不是一次。
  - 另一头：谭季平在爱多亚路口被捕，沪渝断电。

### 第6章 年刊（11月—12月中）

- **危机**：★承舟奉李士群之命送年刊到吕班路，楼下停着吴四宝的车。
  - 李士群的话："他要是说错一句，你就不用下来了，让四宝上去。"
  - 读者知道，这是两人出狱后第一次见面，也是一场考试，答错就是一条命。
- **正面交锋**：★蟹壳黄、年刊、旧照片。两人当着楼下的车说话。每一句表面在叙旧，底下都是攻防，承舟在暗中替墨言"提词"。
  - 墨言在年刊上留的那句话（"老程出题"）保留。前面已经补了他为什么写不说的理由。
- **DDS 下棋**："寄吧"。保留。
- **知微高光**：★十一月二十九日子夜，旧波长有人冒发，她当场用手法识破，写成一场紧张的夜戏：她手上发报，桌上放着一把剪刀，楼下有人敲门。
- **承舟高光**：★承舟揪出孙景和写在台前：他在情报科当众把两份抄件摊开，孙景和的笔迹露馅，承舟不抓他，反过来逼他给森田递假话。读者看见承舟翻纸的本事。
- **钩子**：李士群把底片交给承舟："年底之前还给沈先生。"不提条件，等着看墨言烧还是交。

### 第7章 皮货店（12.21—12.26）

- **郑苹如线**：史实不动，刺丁失手，大衣，"请"进七十六号。
  - 写法：从她的视角写那一分钟的玻璃门、街口的摊贩、枪声。
- **底片线**：★改成一场两个人隔门的夜戏。
  1. 夜里有人敲墨言的门，敲法是四舍的暗号。
  2. 墨言手里握着枪站在门后，不知道门外是承舟一个人，还是承舟带着人。
  3. 门缝里塞进来一个信封。承舟隔门说了半句："题是给两个人出的。"
  4. 两人隔着一块门板站了很久，谁也没开门。
- **高光**：墨言不拆不烧，交给区长。"不要"破局，保留。
- **钩子**：李士群对承舟说"你那位同窗，钓不动了"。
  - ★同一天，承舟在楼上方窗里看见郑苹如被押进后楼，膝上搭着那件大衣。他知道这个姑娘活不长了。下一卷要写她怎么死。

## 第二卷 · 密约

### 第8章 街口那些生面孔（12.28—12.31）

- **郑苹如**：她的那一问保留。这是全卷最好的一刀，写足。
- **危机**：★墨言去静安寺旧书店的路上发现自己被跟。他甩掉尾巴到了书店对面，看见茶摊上的两张新面孔。
  - 改成一场跟踪与反跟踪的追逐。他在静安寺的香客里换了三次方向。
- **承舟线**：托方少棠给书店掌柜递话（已改好）。
  - ★加一个危险：方少棠出书店时被跟回照相馆，承舟在对面马路上看见了，却不能过去。
- **钩子**：日汪密约三十日签字。三十一日，一份高宗武住进广慈医院的呈报放到承舟桌上。他可以压下，也可以上报。

### 第9章 胡佛总统号（1940.1.1—1.8）

- **危机**：★双线倒计时。
  - **承舟**：呈报一交，父亲就能出地下室；可交了，高宗武可能走不了。
  - **墨言**：★区长命令他协助杜家的人把高宗武从广慈后门送上胡佛总统号。
- **正面交锋**：★两人站在对立的两边，却都不知道对方的位置。
  1. 承舟在呈报上写清日子，这是他投敌以来做得最彻底的一件事。
  2. 呈报被周佛海压了两天。
  3. 三号下午晴气的人守病房，墨言扮成修士在后门接人，一辆黑汽车停在街口。
  4. 后门的修女把高宗武交出来，墨言和晴气的人隔着二十步。
- **反转**：晴气的人守的是病房和码头，没守后门。这正是承舟呈报上漏写的一句"病房朝东有后门"。
  - 读者到这里才明白：承舟上报了，又留了一扇门。他也不知道门外的是墨言。
  - **注意**：史实是高宗武、陶希圣由杜月笙安排出走。墨言作为区里的人在杜家护送队里，不改变结果。我会查实这一段的经过，再定细节。
- **钩子**：影佐看了呈报的落款，训斥李士群，提拔承舟。李士群说"日子留给我写"。
  - 父亲移进福民医院。承舟剥橘子，一夜没睡。

### 第10章 四舍的人不欠账（1月中）

- **危机**：方少棠在北站被森田抓走。
  - ★承舟必须在他招供以前把人要回来。写一场承舟闯宪兵队的戏：带着梅机关的公文对森田，森田故意让他听隔壁的动静。
  - 十根手指，不写过程，写承舟听见的声音。
- **高光**："四舍的人不欠账"。保留，作为全章的泪点。
- **墨言线**：★撤离吕班路写在台前。
  - 他点上添满油的灯，上好留声机的发条，从后窗出去。
  - 虹口的便衣撬门时，他就趴在对面屋顶上，听着留声机在屋里唱了一夜。
- **电车相会**：师徒最后一面保留，压成一场紧张的戏。
  - 邵的尾巴就坐在最后一排，两人说话不能看对方。
  - 邵说："这个名字我说了，你活不过正月。"
- **钩子**：森田把方少棠的真笔录锁进柜子："这一张，留给顾科长。"

### 第11章 斜桥（1月下旬）

- **危机**：★墨言从区长桌上无意间看到回电"事毕即处置"。离邵子钧最后一次递话还有两天。
  - 他要不要去救这个出卖了他的师父？这是全卷最重的选择。
- **出手**：★二十四日夜，墨言去了斜桥。
  1. 他躲在弄堂口，看见程伯雄雇的两个人进了弄堂。
  2. 他的手已经摸到枪。
  3. 邵子钧走过弄口，看见了他，脚步没停，轻轻摇了一下头。
  4. 刀子进去的时候，墨言没有动。
  - 这一场写到最狠，是全书第一个大泪点。
  - "他教我开锁，最后他自己成了锁"保留。
- **大世界高光**：★整场在台前，是全卷最热闹的动作戏。
  - 哈哈镜里认出送牛奶的便衣。
  - 把他引上三楼赌台，故意撞翻台面。
  - 青帮的人围上来，便衣拔枪，被打翻，身上搜出宪兵证。
- **代价**：墨言的脸被看清了。"枪手不是诱饵。"
- **钩子**：承舟签"沈墨言潜逃香港，本案结"，补了一张船行客单。他以为这一笔把墨言摘干净了。
  - 这张客单下一章就成了森田手里的刀。

### 第12章 不要打我的脸（2月上旬，李士群视角）

- **郑苹如**：史实不动，写足。
- **危机**：★森田当面摊牌，写成承舟和森田一对一的对手戏。
  - 福民医院走廊的窗台上，森田摆出三张纸：补的客单、结案抄件、方少棠的真笔录。
  - 他一边削苹果，皮一圈不断："正月底以前，我要见到真的沈墨言。"
  - 承舟的回答要硬，不能只是沉默。
- **父亲**："墨言那孩子还好么？"保留。
- **钩子**：正月底只剩二十天。承舟手里没有墨言，只有一叠森田的把柄。

### 第13章 刀柄朝里（2月中下旬）

- **承舟高光**："刀柄朝着我"。保留，写成承舟和李士群的一场正面交锋：承舟把对自己不利的那张手印也递了过去。
- **危机**：★森田的人到圣约翰抓小禾。
  - 承舟不能露面救人，只能动一张纸：他在虹口的条子上把"查"改成"缓查"，只能拖一夜。
  - 那一夜，墨言和承舟分头救她，彼此不知道。
- **反转**：★小禾半夜收到"兄长旧友"的字条，以为是哥哥。第二天早上，知微认出了那几个往右斜的"兄"字。
- **墨言线**：十六铺煤驳。
  - ★改得更险：他已经一只脚踏上跳板，才看见码头上青帮的手势，当着日本兵的面折回。
  - 太古轮被扣搜了一天一夜。
- **钩子**：晴气派承舟三月去吴淞口验船："凡是姓沈的，你都看一看。"

### 第14章 汽艇（3月上中旬）——第二卷高潮

- **承舟高光**：吴淞口验船写在台前。脚夫孙景和对不上花名册，承舟当众认出，森田被停外勤。
- **危机**：承舟寄"莫走水路"的信，知微收到。墨言要在十三日夜上宁波帆船。
- **高光**：★高桥芦棚夜戏，全卷最大的场面。
  1. 汽艇的探照灯扫过江面，墨言蹲在芦苇里，离帆船只有二十步。
  2. 他按信上的话没有上船，看着晴气的人跳上帆船搜人。
  3. 探照灯扫过芦苇，停住了。灯后站着的人穿灰大衣。
  4. 灯停了三秒，移开了。
- **认人**："没有沈墨言。"这是真话。
  - ★读者此刻不知道承舟是否看见了芦苇里的他。这是全卷留给读者的悬念，第五十章回收。
- **父亲**："货是货，账是账。"保留。
- **钩子**：晴气在帆船老大的供词上添一个"沈"字，摆到承舟桌上，看他怎么改。

### 第15章 石子（3月下旬）

- **危机**：晴气开价，十天之内带来林知微，顾鸿年回南市。倒计时明写在每一节开头：第十天、第七天、第三天……
- **知微高光**：★从圣三一堂侧门甩掉车夫，写成完整的追踪戏：教堂、唱诗班、换衣服。她把旧码电报和签条交到区长手里，区长说"放下"。
- **承舟**：说她是自己放出去的"石子"。这是在救她，也是在把她拴上自己的线。墨言听到这句话，把"九"字撕成两半。
- **钩子**：第十天到了，梅机关扑空。晴气对承舟说："那么，就换一个人吧。"
  - 这一句接第三卷开头的徐家汇空屋。
